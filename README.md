# The ELBuddy Task Trainer Repository

The ELBuddy is programmed with an Arduino UNO R4 Wifi.

MAINCODE.ino is the code that is currently programmed onto the manikin. 

### PLEASE NOTE :
the syntax used for the audios in the main code is with respect to the SD card currently inserted. A new SD card will require uploading the sounds found in AUDIOFILELINKS.md and changing the track numbers as needed.

The TESTING folder holds all testing/troubleshooting codes for all the electronic components:
- Both magnets (they are connected to the same pin, so they will have to be tested simultaneously)
- Linear Resonance Actuator (LRA) (on the elbow) and LRA
- MP3 Player and Speaker

Happy decoding and troubleshooting!
